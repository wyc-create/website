# 记忆问题类型清单（体检与维护共用，唯一来源）

「记忆健康检查」按本清单**只出报告不动手**；「定期维护」对用户确认的问题项**动手执行**。两流程共用本清单，禁止在各自文件里复制判定标准。

| # | 检查项 | 严重度 | 判定标准 | 建议动作 |
|---|--------|--------|----------|----------|
| 1 | 断链 | 中 | 记忆/AGENTS.md/track 摘要引用的文件或章节不存在 | 补齐或删引 |
| 2 | 矛盾 | 高 | 与其它记忆文件或 git 事实（提交历史/分支状态）冲突 | 以有证据的现状修正 |
| 3 | 过期 | 中 | 当前阶段长期未更新；已完成工作仍挂待办；旧结论未覆盖 | 按「弃旧从新」覆盖，留一行更正指针 |
| 4 | 重复与互抄 | 中 | 同主题多份；记忆与 track 详情/模板/_temp 报告互抄全文 | 主干留结论+指针，其余删 |
| 5 | 敏感信息 | 高危 | 出现密码/密钥/Token/Cookie/私钥 | 立即删除并通知用户，**不打印内容** |
| 6 | 规模超限 | 中 | MEMORY.md 逼近 200 行/25KB；主干子文件超 8KB/120 行（豁免项除外） | 细节外移 track 详情子夹，摘要留指针 |
| 7 | 索引失配 | 中 | MEMORY.md 与实际文件不一一对应；三节结构缺失 | 修索引 |
| 8 | 方向纯度 | 中 | track 摘要混入实验数字/踩坑细节；一个 track 混多方向；详情文档缺秒级时间戳 | 拆分归位、降级到详情子夹、补戳 |
| 9 | harness 泄露 | 中 | 通用记忆出现工具专属名词（UI/命令/API/定时任务名） | 拆到 `memory/harness_<工具名>.md` 并标 `[harness-specific]` |
| 10 | harness 无价值 | 中 | harness 文件条目不满足准入门槛：非实测、一次性观察、身份/偏好类 | 压缩或删除条目 |
| 11 | temp 双层失同步 | 中 | `_temp/` 有日期文件夹未登记；temp_recent 超 3 个日期未沉降；archive 缺对应流水 | 补登记、压缩沉降 |
| 12 | 主干被分支篡改 | 高 | 非 main 分支修改了共享主干文件（概况节/纪律/AGENTS.md/他人 track）；记忆正文自指「当前分支」 | 还原主干改动；分支内容迁回本分支 track |
| 13 | worktree 位置 | 中 | `git worktree list` 中 worktree 嵌套在项目根内部 | 按 git.md 迁移到兄弟目录 |
| 14 | 模板漂移与版本 | 中 | 项目纪律与模板差异未走回流；已安装 skill 版本低于项目内 skills/ 副本 | 逐条问用户：回流/项目定制/删除 |
| 15 | AGENTS.md 失配 | 中 | AGENTS.md 与工作区根 AGENTS.md（唯一权威）或实际约定不一致 | 在工作区根改，merge 到各分支 |
| 16 | Git 与 _temp 规范 | 低 | 未提交/未推送改动；`_temp/` 任务文件夹缺 README 或时间戳 | 补提交；补 README |

**审计边界**：`temp_archive.md` 与 `track_<方向>/` 详情子夹豁免规模与内容审计，只查「索引是否标注了默认禁读」。

**分级输出**（体检用）：高危 → 高 → 中 → 低；每项记「位置 / 类型 / 严重度 / 建议动作」。
