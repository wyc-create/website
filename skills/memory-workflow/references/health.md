# 记忆健康检查工作流（只读模式）

## 目标
审计记忆系统健康度，输出问题清单，**不修改任何记忆文件**。需要动手整理时交给「定期维护」。

> 分工：体检只出清单；维护才动手。体检发现问题 → 用户确认 → 维护执行。

## 步骤

1. **读取现状**：`memory/MEMORY.md` + 全部主干子文件（含 temp_recent）+ track 摘要 + 项目根 AGENTS.md。`temp_archive.md` 与 `track_<方向>/` 详情子夹**不读内容**，只查索引是否标注「上限豁免·默认禁读」。

2. **按 `references/issues.md` 16 项逐项审计**：每项记「位置 / 类型 / 严重度 / 建议动作」。

3. **输出清单**：按严重度排序（高危 → 高 → 中 → 低）。

4. **等用户确认**：本流程默认零修改；用户确认后转交「定期维护」执行（注意维护的分支作用域限制）。

5. **汇报（增量）**：除 SKILL.md 统一项外，须报告问题总数与分级、是否零修改。
