# 上下文压缩工作流

## 触发

自然语言：压缩上下文 / 压缩记忆 / compact（可附带保留项说明，如「保留当前任务与未决风险」）

## 目标
当对话上下文过长时，主动压缩上下文中非关键信息，释放上下文空间。

## 执行规则

**保留**（必须保留在上下文中）：
- 当前目标
- 已完成和未完成事项
- 已修改文件的关键设计决定及原因
- 失败方案及其证据
- 测试结果
- 未解决风险
- 下一步验证计划

**删除**（不保留在上下文中）：
- 闲聊
- 重复输出
- 过时计划
- 已经失效的尝试/方法

## 注意事项

- 压缩前，先与会话收尾工作流协作，将关键信息同步进项目记忆（`memory/`）。
- 压缩后，如果用户需要恢复细节，通过记忆系统读取。
- 压缩操作本身不修改记忆文件，只清理当前上下文。
